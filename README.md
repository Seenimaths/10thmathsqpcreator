   - All **1,834 Bilingual Questions** (Tamil & English Medium across Chapters 1–8 + Practical Geometry & Graphs) load natively in milliseconds.

   - Fixed the 97-question truncation bug so selecting `100M — 1 Mark Test (100×1=100M)` always generates and renders **all 100 questions (Q.1 to Q.100)** without clipping at the bottom of page 2, whether conducting a full-portion exam, a single-chapter test, or a combined multi-chapter exam.

4. **Conduct Individual Chapter (1 Ch) or Combine 2+ Chapters Only Exam via Checkboxes**:
   - Use the **Top Chapter Checkbox Bar** or **Sidebar Module 1 Chapter Checkboxes** to tick any single chapter (`Ch 1`–`Ch 8`) or combine 2 or more chapters (`Ch 1 + Ch 2`, `Ch 1 + Ch 3 + Ch 5`, etc.) plus `8M Geometry / Graphs` and immediately generate any exam pattern (`25M`, `50M`, `100M`, or `1M / 2M / 5M / 8M Individual Tests`) strictly from the ticked chapters.

## Quick Start & GitHub Pages Deployment

1. Open `index.html` directly in any desktop or mobile browser — no server or build step required.
2. To host on **GitHub Pages**:
   - Upload all files in this repository to your GitHub repository root (or run `deploy-github.bat` / `deploy-github.sh`).
   - Go to **Settings -> Pages -> Source: Deploy from a branch (`main` / `/root`)**.
   - Your web app will open immediately at `https://<your-username>.github.io/<repo-name>/`.
