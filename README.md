## 🚀 How to Host on GitHub Pages (Step-by-Step)

1. Create a new repository on [GitHub](https://github.com/new) (e.g., `seeni-xqp-studio-v12`).
2. Extract this ZIP file (`Seeni_XQP_Creator_Studio_V12_Encrypted_GitHub_Repo.zip`).
3. Upload all extracted files (`index.html`, `seeni_xqp_creator_studio_v12_direct.html`, `manifest.json`, `sw.js`, `.nojekyll`, `assets/`, `README.md`, `LICENSE`) to your GitHub repository — or double-click `deploy-github.bat` (Windows) / run `./deploy-github.sh` (Linux/Mac).
4. In your GitHub repository, open **Settings → Pages**.
5. Under **Build and deployment → Source**, select **Deploy from a branch**, choose **`main`** and folder **`/ (root)`**, and click **Save**.
6. Within 60 seconds, your encrypted web app will be live at:  
   `https://<your-github-username>.github.io/<repository-name>/`
